**Палисад** — offline-first PWA для учёта питомников растений (Vue 3 + PrimeVue / Node.js + Express + PostgreSQL).
Полное описание продукта — [`general.md`](../general.md), обзоры — [`general-overview.md`](general-overview.md),
[`backend-overview.md`](backend-overview.md), [`frontend-overview.md`](frontend-overview.md),
план v2 — [`v2-roadmap-proposal.md`](v2-roadmap-proposal.md).

## Текущее состояние

**MVP (v1) реализован end-to-end:**

- Backend: модули 0–13 (инициализация, БД/миграции, auth, питомник, RBAC, сотрудники,

## Принципы работы (из роадмапа)

- Каждый этап закрывается end-to-end (схема → backend → frontend → базовый тест) и отгружается отдельно.
- Новые поля — `NULL`-able или с дефолтами; сохранять `updated_at`, `deleted_at`, CHECK, partial-индексы.
- Новые офлайн-сущности — продумывать предзагрузку и мутации через `sync_queue`; агрегации (себестоимость, отчёты) — только онлайн.
- Себестоимость и CRM — зоны повышенного риска, требуют предварительного обсуждения с заказчиком.
